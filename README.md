# Искра

Статический сайт. Сервер, Node и база не нужны — данные живут в браузере посетителя.

## Как открыть на GitHub Pages

1. Распакуйте архив. Внутри должны лежать файлы, а не одна папка.
2. На GitHub создайте **новый репозиторий** (Public). Имя любое, например `iskra`.
3. На странице пустого репозитория: **uploading an existing file** → перетащите **все файлы** в окно.
4. Важно: в корне репозитория должен быть виден `index.html`. Не кладите файлы внутрь папки.
5. Commit changes.
6. **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (или `master`), folder: **/ (root)**
   - Save
7. Через 1–2 минуты сайт откроется по адресу:

   `https://<ваш-логин>.github.io/<имя-репозитория>/`

Если страница белая — файлы лежат во вложенной папке. Перенесите `index.html` на верхний уровень репозитория.

## Что здесь

| Файл | Зачем |
|---|---|
| `index.html` | Приложение целиком |
| `manifest.webmanifest` | Установка на экран Домой |
| `sw.js` | Офлайн-кэш |
| `favicon.svg` | Иконка вкладки |
| `icon-192.png`, `icon-512.png` | Иконки PWA |
| `.nojekyll` | Чтобы GitHub не обрабатывал сайт как Jekyll |

## Свой домен

Settings → Pages → Custom domain. Файл `CNAME` GitHub создаст сам.
